# Embedding geography — do corpus sources occupy distinct regions?

Model `artifacts/hf-tt-tnt-1024a` (embedding matrix only), corpus `artifacts/corpus`, 1,000,000 words read per source, generated by `scripts/probe_embedding_geography.py`.

tt-tnt-1024a, embedding matrix only; CPU, no device touched.

## Why this exists

A proposed sampler would lay the 32,000-token vocabulary onto Blackhole's Tensix grid and sample by spatial neighbourhood, so that *direction on the grid* means *corpus register*. That only works if tokens characteristic of different sources already occupy distinguishable regions of the embedding space. If they do, the layout is **discovered**; if they do not, any layout is **imposed** and the claim is decoration. This measurement decides which, before a kernel is written.

## Method, in brief

- Characteristic tokens are chosen by **log-odds ratio with an informative Dirichlet prior, z-scored** (Monroe et al. 2008), prior strength 1000, minimum 25 occurrences in the claiming source, top 150 per source, winner-take-all so the label sets are disjoint. Raw frequency says nothing (every source's commonest token is the same function word); tf-idf has no notion of sampling noise and would let a small source fill its list with accidents.
- Per-source counts come from a prefix of each prepared source file, one shared word budget per source — the same discipline `scripts/score_behaviour.py`'s register signal uses, differing only in that newlines are preserved, because this profile is over the model's byte-level BPE vocabulary rather than over whitespace words.
- The embedding matrix is read straight from `model.safetensors` (one tensor, never the whole model). The model ties its embeddings, so this is also the output head.
- k-NN purity is over **cosine** neighbours, self excluded. Cosine because embedding norm tracks token frequency more than meaning.
- Every headline is reported against three baselines: **chance** (uniform guessing at the realised class sizes), a **label-permutation floor** (identical computation, labels shuffled — holds geometry and class sizes fixed, destroys only the correspondence), and a **frequency-only control** (features = log corpus count and embedding norm, containing no directional information at all).
- Two token-selection conditions, because the statistic favours frequent tokens: `all`, and `content` — the same, after excluding the 500 globally most frequent tokens. If the geography is a frequency artefact it collapses in `content`.

## What this does and does not show

**Does.** That source identity is recoverable from embedding geometry alone, far above every baseline computed here, and that the recovery survives removing the function-word and punctuation core of each source's profile. The regions are real and they are linearly separable, which is the property a grid layout needs.

**Does not.** That the geometry encodes *source provenance* as such. A source differs from another in subject matter as well as in register — `procedural`'s characteristic tokens are food and kitchen words, and food words would cluster in any embedding of any corpus. What is measured here is that corpus source is legible in the space, not that the model represents "which file this came from". For the grid proposal that distinction does not change the answer (a region is a region either way), but it does change what a direction can be claimed to *mean*: subject matter and register together, not provenance.

**Also does not.** Establish anything about text the model generates. This is a measurement of the embedding table, not of behaviour; `scripts/score_behaviour.py` is where register in actual completions is measured, and its register control scores 99.9% on tinystories against 63.9% on folklore — the observation that prompted the narrative-entanglement contrast above.
