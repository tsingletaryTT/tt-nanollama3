# Behavioural quality — tt-tnt-384s512-vs-tt-tnt-1024a (prompt set B)

Baseline `artifacts/hf-tt-tnt-384s512` (tt-tnt-384s512) vs candidate `artifacts/hf-tt-tnt-1024a` (tt-tnt-1024a), both scored on **prompt set B** (`evaluation_prompts_b.json`). 32 and 32 completions per prompt respectively, over 45 shared prompts. Generated by `scripts/score_behaviour.py --compare`.

## Method, in brief

- **Paired by prompt.** Both runs answered the same frozen prompts, so the difference is computed within each prompt and averaged over prompts. That removes between-prompt variance, which is most of the variance here.
- The `difference` column is `candidate - baseline`, mean ± SEM **over prompts**, with its 95% interval. A difference whose interval spans zero is reported as **no change** -- not as a small improvement.
- `better` states which direction counts as an improvement for that signal, so a regression is reported as a regression.
- `min. detectable` is `1.96 × SEM` of the difference: the smallest change this comparison had the power to call. Read every **no change** verdict against it -- a null result only means "nothing there" for effects larger than that number.
- **Both runs used prompt set B**, and a comparison across sets is refused rather than computed. The project's frozen sets are reported side by side, never averaged together.
